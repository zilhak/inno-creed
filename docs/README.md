## 이 문서들의 원칙

- **실증으로 확정된 사실만 담는다.** 추측·미확인 내용은 넣지 않는다. "될 것 같다"는 문서화하지 않고, 실제 호출해서 응답을 확인한 것만 적는다.
- **조사 과정·미확정 가설·캡처 원본은 여기 넣지 않는다.** 결론만 남기고, 그 결론이 무엇으로 확인됐는지를 함께 적는다.
- 값이 사람마다 다른 것(사번·테넌트 ID 등)은 자리표시자로 쓴다. 실제 값을 문서에 박지 않는다.
